# 方屿 Blockhaven

需要 Node.js 22。

安装：`npm ci`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，打开 http://localhost:8111。

## 本地存档能力

存档全部保存在浏览器 `localStorage` 的单个 vault 键中，无需联网：

- **多个世界槽位**：可新建、切换多个独立世界，每个槽位维护各自的历史版本。
- **可恢复的历史版本**：保存时写入版本链，链由「完整快照 + 增量」组成，每 3 个增量落一次快照，避免每次完整复制；删除任意中间版本时，其变更会折叠进后继条目，后续版本仍可正常读取。
- **后台保存不打断建造**：点击保存即冻结当时的文档快照，写入在后台进行，期间可以继续建造；完成提示只对应实际写入的那个版本，保存期间新增的方块不会被标记为已保存。
- **切换隔离**：切换世界会作废旧槽位的在途保存令牌，迟到的写入无法覆盖新槽位。
- **空间治理**：每个槽位默认保留 10 个版本；本地空间不足时自动从最早版本开始清理，每个槽位的最新版本始终保留，也可以手动清理较早版本。
- **可撤回的载入**：切换世界、重载、恢复历史版本、导入前若有未保存现场，会先保留快照，可一键撤回，原世界、选区与库存原样恢复。
- **独立文件导入导出**：任意世界或历史版本都能导出为单个 JSON 文件；导入的文件总是成为新槽位，不覆盖现有世界。
- **旧版升级**：首次打开时，旧的单槽存档（`blockhaven-world-v1`）会自动迁移为带「旧版迁入」标记的首个世界；迁移成功后才删除旧键。

## 测试

- 逻辑与模型测试：`npm test`
- 浏览器冒烟测试（需先安装 Playwright 浏览器及系统依赖）：`npm run test:e2e`
